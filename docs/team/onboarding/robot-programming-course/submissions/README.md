# Submission folders
Use `submissions/<student-id>/<module>/<checkpoint>/attempt-01/`.

Each attempt contains `SUBMISSION.md`, a `source/` snapshot, and `evidence/` (test output, CSV or WPILib log, and any graph). Make attempt-02 when revising; link to the earlier attempt. Put prediction text in the file before running. Update the progress sheet only after the artifact exists. Never overwrite old evidence when exporting the next run.

Students set `ready-for-review` when ready. The mentor writes feedback and sets `changes-requested` or `reviewed`. A conversation is recorded by date and one sentence about the concept discussed. Keep student submissions private.
