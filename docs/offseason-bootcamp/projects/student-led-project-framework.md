# Student-Led Project Framework

## Summary

Create a repeatable process for students to propose, scope, and own offseason projects without losing technical rigor or mentor visibility.

## Why This Project Matters

- Student ownership is valuable, but unstructured project selection can lead to ideas that are too vague or too large.
- A lightweight framework helps mentors guide projects without taking ownership away from students.
- Good project framing makes sign-up and accountability much easier.

## Proposed Approach

1. Create a simple project proposal template.
2. Require each student or group to explain the problem, goal, and success criteria.
3. Ask students to identify code areas, hardware needs, and risks.
4. Review each proposal for scope and readiness.
5. Convert accepted proposals into milestone-based work with a final demo or report.

## Deliverables

- A student project proposal template.
- A review checklist mentors can use during sign-up.
- A simple ownership model for individual students or small groups.

## Competency Checklist

- Can explain a project goal clearly.
- Can break a project into smaller steps.
- Can identify what help or hardware is needed.
- Can communicate status and blockers consistently.
- Can finish with a demo, write-up, or recommendation.

## Good Stretch Goals

- Add a rubric for project difficulty.
- Match project types to beginner vs advanced students.
- Build a project board that makes ownership visible to the whole team.
