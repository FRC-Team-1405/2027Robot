# Offseason Project Summary

This file separates the offseason project ideas from the mentor retro to make project planning easier once the boot camp phase is complete.

## Boot Camp First

These projects should begin after students have gone through enough boot camp work to show they are ready for more independent technical work.

## How To Use These Guides

- Use the summary first to decide which project matches the student's skill level and the team's available hardware.
- Use the individual project guide to define scope, deliverables, and readiness expectations.
- Treat the competency checklist as a readiness screen, not as a hard gate that prevents mentorship.

## Shared Expectations Across Projects

- Students should know how to read existing robot code before owning a project.
- Students should be able to explain what they are measuring, why it matters, and how they will validate the result.
- Logging, documentation, and clear communication should be part of every project, not optional extras.
- Each project should end with a short written result, demo, or recommendation back to the team.
